Frequently Asked Questions

What is this addon?

Bend Exact is a Blender addon that applies the exact "tut bend" Geometry Nodes setup to your mesh. It creates a precise bend deformation using curve sampling, rotation vectors, and position math.

Do I need to know Geometry Nodes?

No! The addon handles everything for you. Just install it, select your object, and press the button. The Geometry Nodes setup is applied automatically.

Can I customize the bend?

Yes. You can optionally provide an existing curve object to control the bend shape. The radius and range parameters are also adjustable through the Geometry Nodes group inputs.

Is it compatible with my Blender version?

Bend Exact requires Blender 4.2 or later. It uses the standard Geometry Nodes API and should work with any 4.2+ installation.
